# Networking Engineering Lab

A hands-on learning portfolio documenting my journey into networking engineering, from foundational concepts to practical network design and troubleshooting.

## Learning approach

This portfolio combines:

* Beginner-friendly networking theory.
* Practical exercises using Cisco Packet Tracer.
* Network diagrams and topology documentation.
* Connectivity tests and troubleshooting.
* Knowledge checks and assessments.
* Lessons learned and verified results.

---

## Environment and tools

* **Host operating system:** Windows 10 Pro, 64-bit
* **Network simulation:** Cisco Packet Tracer 9.0.1
* **Virtualization:** Oracle VirtualBox
* **Version control:** Git and GitHub
* **Lab documentation:** Markdown

---

## Phase 0 — Environment Readiness and Foundations

Phase 0 establishes the learning environment and introduces basic network communication.

### Completed practical work
1. Environment readiness and network configuration checks.
2. First LAN with three PCs connected to a Layer 2 switch.
3. Ethernet switching and MAC address learning.
4. Ethernet frames and forwarding in Simulation Mode.
5. Address Resolution Protocol (ARP) and address resolution.
6. IPv4 addressing, subnet masks, CIDR and subnetting.
7. Practical communication tests between devices in the same and different subnets.
8. Phase 0 knowledge assessment — 10/10.

### Phase 0 project files
The `phase-0-environment/` folder contains:
* Practical lab reports in Markdown.
* Cisco Packet Tracer topology files.
* Documented configurations, observations and verification results.

## Portfolio principles

* Document practical work and actual results.
* Explain the purpose of commands and configurations.
* Verify connectivity rather than assume success.
* Use only networks and systems I own or am authorized to test.
* Keep credentials, private keys, passwords and sensitive personal network information out of public files.
